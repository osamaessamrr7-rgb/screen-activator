# 📺 Screen Activator Portal (بوابة تجميع وتفعيل الشاشات)

نظام خفيف وسريع جداً مبني بـ **FastAPI** لتجميع أكواد تفعيل الشاشات والتطبيقات الذكية من الزبائن وتفعيلها دفعة واحدة.

## 🚀 النشر المجاني بنقرة واحدة (Free Hosting):

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/osamaessamrr7-rgb/screen-activator)

## 🌟 المميزات:
- **واجهة العملاء (`/`)**: صفحة عصرية ومتجاوبة مع الموبايل لإرسال كود الشاشة بنقرة واحدة.
- **لوحة التحكم (`/admin`)**:
  - عرض جميع الأكواد المجمعة سطر وراء سطر.
  - زر لنسخ كل الأكواد دفعة واحدة للحافظة.
  - زر لتنزيل الأكواد كملف `.txt`.
  - زر لتفريغ القائمة بعد التفعيل.
  - تحديث تلقائي مع رنة تنبيه صوتية عند استقبال كود جديد.

## 💻 التشغيل المحلي:
```bash
pip install -r requirements.txt
python server.py
```
